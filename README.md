# Thamar Zananiri landing page

A responsive, dependency-free static site. Serve this directory using:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Publish `index.html` and `style.css` together to a static hosting provider. No build step, secrets, or external assets are required.
